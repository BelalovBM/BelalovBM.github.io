# BelalovBM.github.io

The root page of https://belalovbm.github.io/: a list of the projects and the sitemap for search engines. Each project's own page lives in that project's repository (GitHub Pages) under `https://belalovbm.github.io/<repository>/`.

For a new project: add a block to `index.html` and a line to `sitemap.xml`.
